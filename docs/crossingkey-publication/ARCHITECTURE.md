# Intended machine-commerce architecture

Discovery and capability policy feed purchase authorization and payment handling.
Verified payment enables purchase records and entitlements. Entitlements gate
capability execution; result hashes, receipts, .xkey records, and Kennekarte
provenance support binding and auditability.

Compatibility requirement: preserve x402 v1 and v2 behavior. This publication
script does not implement or verify either protocol and changes no payment logic.
Authoritative behavior is the actual source plus independently reviewed tests.
